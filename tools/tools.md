# Tools and Libraries

These are the primary software frameworks and platforms used to implement Human-in-the-Loop (HITL) pipelines and active learning.

1. **MedSAM (Medical Segment Anything Model)**  
   *Purpose:* A specialized foundation model for rapid AI-assisted spatial segmentation in radiological and histopathological imaging.  
   *Link:* [MedSAM on GitHub](https://github.com/bowang-lab/MedSAM)

2. **Label Studio**  
   *Purpose:* Open-source multi-modal data annotation tool that tightly integrates machine learning backends for active learning and AI pre-labeling.  
   *Link:* [Label Studio](https://labelstud.io/)

3. **DeepCell / AnnDictionary**  
   *Purpose:* Bioinformatics frameworks leveraging LangChain and Scanpy to automate cell-type annotation in scRNA-seq datasets using LLMs.  
   *Link:* [DeepCell](https://deepcell.org/)

4. **cleanlab (Confident Learning)**  
   *Purpose:* A framework for systematic label noise purification, allowing models to identify, characterize, and remove label errors from datasets before training.  
   *Link:* [cleanlab](https://cleanlab.ai/)

5. **CVAT (Computer Vision Annotation Tool)**  
   *Purpose:* Open-source tool tailored for annotating images and videos with AI-assisted bounding boxes and polygon interpolation.  
   *Link:* [CVAT](https://www.cvat.ai/)
