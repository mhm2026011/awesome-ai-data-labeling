# GitHub Implementations

Existing high-quality open-source codebases and implementations relevant to AI-assisted data curation and model training.

1. **bowang-lab/MedSAM**  
   *Relevance:* The official implementation of Medical SAM, crucial for testing zero-shot prompt-driven segmentation against manual baselines.

2. **HumanSignal/label-studio**  
   *Relevance:* The leading open-source platform for testing Human-in-the-loop workflows across text, vision, and audio data.

3. **cleanlab/cleanlab**  
   *Relevance:* Essential for reproducing Confident Learning experiments to detect and filter out manual annotation bias and noise.

4. **MIC-DKFZ/nnUNet**  
   *Relevance:* The state-of-the-art supervised baseline model used to evaluate the upper boundary of clinical accuracy in volumetric segmentation.

5. **opendatalab/labelU**  
   *Relevance:* An open-source multi-modal data annotation platform with native support for AI auto-annotation.
